# Плёнки: как устроены и как сделать свою

[English](films.md) · **Русский**

Плёнка в «Проявке» — это не картинка и не скачанный LUT, а десяток чисел в `PRESETS` в [`bot/proyavka/film.py`](../bot/proyavka/film.py). Из них бот на лету строит 3D-LUT для цвета и сверху добавляет свечение, зерно и виньетку.

## Попробовать

```bash
.venv/bin/python bot/try_films.py photo.jpg              # все плёнки на одном листе -> photo_films.jpg
.venv/bin/python bot/try_films.py photo.jpg my_film      # твоя плёнка в полном размере
.venv/bin/python bot/try_films.py photo.jpg my_film 150  # с силой 150 %
```

Поменял число → запустил → посмотрел. Telegram и сервер не нужны. Когда нравится — перезапусти бота: `sudo systemctl restart proyavka-bot`.

## Свой LUT без программирования

Есть готовый LUT из Lightroom, Resolve или купленного набора? Пришли файл `.cube` боту в чат или нажми «Свой LUT» в конце списка плёнок в «Проявке». Он появится среди плёнок под фото, в «Проявке», в пачке и в `/film`; сила смешивает его с исходником, засветы, дата и рамка работают как обычно. LUT виден только тому, кто его загрузил. Список и удаление — `/luts` (в «Проявке» — долгое нажатие на LUT). Поддерживаются 3D LUT размером от 2 до 65, до 16 МБ и до 30 штук на человека. В отличие от плёнок «Проявки», LUT — только цвет: без зерна, халяции и виньетки.

## Добавить плёнку

Скопируй любой блок в `PRESETS` и дай ему новый ключ (латиница, строчные, без пробелов):

```python
"my_film": dict(
    name="My Film 400", when=L("улица, вечер", "street, evening"),
    desc=L("тёплые тени, мягкий контраст", "warm shadows, soft contrast"),
    contrast=0.3, lift=(0.04, 0.03, 0.02), sat=0.9,
    shadow_tint=(0.02, 0.0, -0.02), high_tint=(0.02, 0.01, 0.0),
    halation=0.35, grain=0.045),
```

Указывай только то, что отличается от значений по умолчанию (`DEFAULTS` чуть выше `PRESETS`). Новая плёнка сразу появится везде: кнопки под фото, лист «Сравнить», `/film`, мини-приложение. `when` и `desc` пишутся на двух языках через `L("по-русски", "in English")`.

Не переименовывай существующие ключи — база хранит их у каждого кадра. Если очень надо, добавь старый ключ в `OLD_KEYS`.

## Параметры

Цвет применяется в таком порядке: насыщенность → гамма → контраст → «плечо» светов → оттенки → уровни чёрного и белого. Значения в скобках — `(красный, зелёный, синий)`.

| Параметр | По умолчанию | Что делает | Попробуй |
|---|---|---|---|
| `sat` | `0.9` | насыщенность; 1 — без изменений | 0.6 приглушённо … 1.35 сочно |
| `gamma` | `(1, 1, 1)` | гамма полутонов по каналам; больше 1 — убирает этот цвет из полутонов | `(1, 0.97, 0.98)` — чуть больше зелёного и синего |
| `contrast` | `0.35` | сила S-кривой | 0.2 плоско … 0.7 жёстко |
| `shoulder` | `0.78` | где начинается мягкий завал светов; меньше — мягче света | 0.7 … 0.85 |
| `shadow_tint` | `(0, 0, 0)` | цвет, добавляемый в тени | `(-0.03, 0.01, 0.02)` — бирюзовые тени |
| `high_tint` | `(0, 0, 0)` | цвет, добавляемый в света | `(0.04, 0.02, -0.03)` — тёплые света |
| `lift` | `(0.03, 0.03, 0.03)` | уровень чёрного по каналам: выцветший, «молочный» чёрный | `(0.05, 0.035, 0.02)` — тёплый выцветший чёрный |
| `top` | `0.975` | уровень белого; меньше 1 — матовые света | 0.93 для выцветшего вида |
| `bw` | `None` | чёрно-белое: смесь каналов вместо цвета | `(0.25, 0.6, 0.15)` мягко, `(0.45, 0.45, 0.1)` тёмное небо, как с оранжевым фильтром |
| `halation` | `0.3` | красное свечение вокруг ярких мест, как рассеяние света в плёнке | 0.15 едва … 0.9 ночная плёнка |
| `hal_thr` | `0.72` | с какой яркости начинается свечение; меньше — светится больше | 0.6 … 0.8 |
| `bloom` | `0.08` | мягкая дымка поверх светов | 0 … 0.15 |
| `soften` | `0.5` | лёгкое размытие против цифровой «звонкости» (в пикселях при 3000 px) | 0 … 1 |
| `grain` | `0.04` | сила зерна | 0.025 тонкое … 0.08 грубое |
| `grain_size` | `1.6` | размер зерна (пиксели при 3000 px) | 1.3 мелкое … 2 крупное |
| `grain_color` | `0.3` | доля цветного шума в зерне; 0 — монохромное зерно | 0 … 0.5 |
| `vignette` | `0.2` | затемнение углов | 0 … 0.3 |
| `hue` | `(0, 0, 0, 0, 0, 0)` | сдвиг оттенка в градусах по шести цветовым полосам: красный, жёлтый, зелёный, голубой, синий, пурпурный; остальные полосы и серое не трогаются | `(0, 0, -22, 0, 0, 0)` — зелень к жёлтому, та самая «плёночная» зелень |
| `bsat` | `(1, 1, 1, 1, 1, 1)` | множитель насыщенности для тех же шести полос | `(1, 1, 0.8, 1, 1.25, 1)` — спокойнее зелень, богаче синий |
| `mix` | `(0, 0, 0, 0, 0, 0)` | смешивание каналов, шесть чисел: сколько красный берёт от зелёного и от синего, зелёный — от красного и от синего, синий — от красного и от зелёного. Диагональ подбирается сама, серое остаётся серым | `(0, 0.06, 0, -0.05, 0.04, 0)` — кросс-процесс |
| `grain_shadow` | `0` | добавочное зерно в тенях, как у негатива; 0 — как раньше | 0.3 … 0.8 |
| `linear` | `0` | 1 — свечение и дымка считаются в линейном свете: шире и мягче, пропорционально яркости источника; на полном размере медленнее | 0 или 1 |

Кнопки **Сила** (25–150 %) смешивают плёнку с оригиналом; зерно и виньетка тоже масштабируются.

## Автовыбор

В режиме «Авто по ситуации» бот смотрит на яркость, цвет и время съёмки в `auto_pick()`: ночь → `night800`, тёплый свет → `amber_neg`, пасмурно → `muted_chrome`, пейзаж → `vivid50`, остальное → `street_neg`. Добавь туда свою плёнку, если хочешь, чтобы она выбиралась сама.

## Засветы

Засветы живут в `LEAKS` (название и описание) и `leak_layer()` (как каждый рисуется). Для нового засвета нужно немного кода рисования — посмотри, как сделаны `orb` или `streak`.
