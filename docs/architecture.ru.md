# Как устроен код

`bot/filmbot.py` — только точка входа (его запускают служба и мастер установки). Весь остальной код — пакет `bot/proyavka/`, по модулю на дело. Модуль импортирует только нижние слои; обращение вверх (и к именам, которые подменяют тесты) — импортом внутри функции, которой это нужно.

| Слой | Модули | За что отвечают |
|---|---|---|
| 0 | `config`, `i18n`, `util` | настройки из окружения и папки с данными; строки на двух языках; мелкие помощники |
| 1 | `film`, `imaging`, `pwa` | движок плёнок (кривые, цветовые полосы, смешивание каналов, свечение, зерно, LUT, свои плёнки, коды обмена); открытие кадров (в том числе RAW), кадрирование, засветы, дата, рамка, листы-превью; значок, манифест и service worker приложения |
| 2 | `database`, `users` | SQLite, схема и миграции, `q`/`run`; пользователи и их настройки |
| 3 | `jobs`, `pools` | задачи в процессах-работниках (только рендер и файлы: ни базы, ни Telegram они не импортируют); пулы процессов |
| 4 | `telegram`, `sessions`, `push` | Telegram API, кнопки, правка сообщений; сессии, вход, подпись ссылок на картинки; Web Push |
| 5 | `scheduler`, `storage`, `photos` | очереди отрисовки по срочности и по кругу между пользователями, пакеты, экспорт, очередь обновления сообщений; место и чистка по лимитам; корзина |
| 6 | `state`, `looks`, `albums` | `state.json`; свои плёнки и каталог сообщества (и приём плёнок от других серверов); альбомы по ссылке |
| 7 | `ingest`, `devices`, `camera` | приём кадров с камеры и из приложения; устройства и API аккаунта; камера пользователя |
| 8 | `invites`, `botui` | приглашения и пользователи; бот в чате |
| 9 | `web` | веб-сервер приложения |

Что полезно знать, прежде чем что-то менять:

- **Плёнки** лежат в `film.py` (`PRESETS`); что делает каждый параметр — в [плёнки](films.ru.md). Прежние значения встроенных плёнок хранятся в `bot/films_v1.json`.
- **Настройки, которые меняются на ходу** (`BOT_TOKEN`, `STORAGE_GB`), всегда читаются и пишутся как `config.NAME`. Остальные настройки импортируются по имени.
- **Имена, которые подменяют тесты** (`telegram.tg_send`, `sessions.check_init_data`, `ingest.fetch_from_vps`, `camera.cam_helper`, `push.webpush`, `config.WEBAPP_HTML`, переключатели `COMMUNITY_*`…), импортируются внутри функций, поэтому всегда видно текущее значение. Подменять их нужно в модуле, где они определены.
- **Тесты** лежат в `tests/` (`python tests/run_all.py`). Они запускают бота целиком с подменённым Telegram и синтетическими кадрами. Модули пакета в тесте импортируйте только после `harness.start()`: `config` читает окружение при импорте.

Язык пользователя: модули выше `users` берут `user_lang` из `users`, а не из `i18n` (там заглушка, которую `users` подменяет при импорте; на это опирается только `speak()`).
