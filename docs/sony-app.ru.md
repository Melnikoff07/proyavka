# Приложение «Проявка» для Sony — установка по шагам

[English](sony-app.md) · **Русский**

Для камер Sony с PlayMemories Camera Apps: a5000/a5100, a6000/a6300/a6500, a7 II / a7R II / a7S II, RX100 III–V, RX10 II/III и других из [списка совместимых](https://openmemories.readthedocs.io/devices.html). Если в меню камеры есть раздел **«Приложение»** — скорее всего, подходит.

Понадобятся: компьютер с Windows или macOS, USB-кабель, 10 минут. Прошивку камеры это не меняет: приложение ставится так же, как официальные из PlayMemories, и удаляется в меню камеры.

## 1. Скачай два файла

- **Proyavka.apk** — со страницы [Releases](../../../releases/latest) этого проекта.
- **pmca-gui** — программа для установки приложений на Sony:
  - Windows: [pmca-gui-v0.18-win.exe](https://github.com/ma1co/Sony-PMCA-RE/releases/download/v0.18/pmca-gui-v0.18-win.exe)
  - macOS: [pmca-gui-v0.18-osx.dmg](https://github.com/ma1co/Sony-PMCA-RE/releases/download/v0.18/pmca-gui-v0.18-osx.dmg) (на Mac может понадобиться [драйвер Sony](https://support.d-imaging.sony.co.jp/mac/driver/11/ja/); закрой «Фото», Dropbox и Google Drive — они перехватывают USB)

Windows может предупредить, что программа неизвестна: «Подробнее» → «Выполнить в любом случае». Это открытый проект, [исходники на GitHub](https://github.com/ma1co/Sony-PMCA-RE).

## 2. Подключи камеру

1. На камере: **Меню → Настройки → USB-соединение → MTP** (или «Накопитель» / Mass Storage — тоже подойдёт).
2. Подключи камеру к компьютеру кабелем и включи её. На экране камеры появится «USB-подключение».

## 3. Поставь приложение

1. Запусти **pmca-gui**.
2. Открой вкладку **Install app**.
3. Выбери пункт **Select an apk** и нажми **Open apk...** → укажи скачанный `Proyavka.apk`.
4. Нажми **Install selected app** и подожди, пока в окне не появится «Task completed successfully». Камера сама покажет процесс установки.
5. Отключи кабель.

Приложение появилось в **Меню → Приложение → Список приложений → Проявка**.

## 4. Положи настройки на карту

1. Отправь своему боту в Telegram команду **/camera** — он пришлёт файл `config.txt`.
2. Вставь карту памяти в компьютер (или подключи камеру в режиме «Накопитель»).
3. Создай в **корне** карты папку `PROYAVKA` (рядом с папкой `DCIM`) и положи в неё `config.txt`.

```
карта памяти
├── DCIM
└── PROYAVKA
    └── config.txt
```

## 5. Добавь Wi-Fi — один раз

1. Включи точку доступа на телефоне (и/или будь рядом с домашним Wi-Fi).
2. **Меню → Приложение → Проявка → Wi-Fi.** Появится список сетей вокруг.
3. Колесом выбери сеть, нажми центральную кнопку, введи пароль экранной клавиатурой → **Подключить**.
4. Если пароль верный — «Сохранено». Сеть отмечается ✓, и дальше камера подключается к ней сама.

Можно сохранить несколько сетей (телефон и дом) — камера возьмёт ту, что рядом. Сохранённую сеть можно выбрать ещё раз: подключиться, сменить пароль или забыть (или кнопка корзины). Сети записываются на карту в `PROYAVKA/wifi.txt` и не теряются, даже когда камера «забывает» Wi-Fi.

## 6. Снимай

1. Режим качества: **JPEG** или **RAW+JPEG** (RAW-файлы приложение не отправляет).
2. **Меню → Приложение → Проявка → Отправить новые** (центральная кнопка — она выбрана сразу).
3. Приложение само включит Wi-Fi, отправит новые кадры, покажет «Готово» и выключит Wi-Fi. Через полминуты кадры в боте. Кнопка **MENU** — выход, **корзина** во время отправки — отмена.

## Если что-то не так

| На экране камеры | Что делать |
|---|---|
| «Нет настроек…» | Нет файла `PROYAVKA/config.txt` на карте — проверь папку и имя файла |
| «Wi-Fi не настроен» | Зайди в «Wi-Fi» и выбери сеть (шаг 5) |
| «Нет Wi-Fi. Не вижу сетей: …» | Включи точку доступа на телефоне; если сменил пароль — Wi-Fi → сеть → «Ввести пароль заново» |
| Клавиатура не появляется | Нажми центральную кнопку на поле пароля |
| «сервер не принял токен» | Файл `config.txt` устарел — возьми новый через /camera |
| «Новых кадров нет» | Всё уже отправлено. Чтобы отправить заново, удали `PROYAVKA/sent.txt` |
| pmca-gui не видит камеру | Другой режим USB (MTP ↔ Накопитель), другой кабель или порт; закрой программы, которые открывают камеру |
