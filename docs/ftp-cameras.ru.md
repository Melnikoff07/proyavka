# Камеры с отправкой по FTP — настройка по шагам

[English](ftp-cameras.md) · **Русский**

Многие новые камеры умеют сами отправлять каждый кадр на FTP-сервер: Sony A7 IV, A7C II, A7CR, A7R V, A1, A9 III, FX3/FX30, ZV-E1 и другие, а также многие Fujifilm, Canon и Nikon. «Проявка» принимает кадры по **FTPS** — это FTP с шифрованием, пароль и фото не летят по сети открытым текстом.

Ниже — названия пунктов для Sony. У других производителей они похожи.

## 1. Данные для подключения

Отправь своему боту в Telegram **/camera**. Он пришлёт:
- адрес сервера, пользователя (`camera`) и пароль;
- файл **cacert.pem** — корневой сертификат, по которому камера проверяет, что подключается к твоему серверу, а не к подменному.

## 2. Импортируй сертификат

Без этого шага камера с включённой защитой откажется подключаться.

1. Скачай `cacert.pem` из чата и положи в **корень** карты памяти (рядом с папкой `DCIM`, не внутрь). Имя файла должно остаться ровно `cacert.pem`.
2. Вставь карту в **слот 1** камеры.
3. **Меню → Сеть → Параметры сети → Импорт корн. сертификата → Функция FTP → OK.**

Сертификат сбрасывается вместе со сбросом сетевых настроек камеры — тогда импортируй его снова.

## 3. Настрой сервер

**Меню → Сеть → Передача/Удалённо → Функция передачи FTP → Настройки сервера → Сервер 1:**

| Пункт | Значение |
|---|---|
| Отображаемое имя | любое, например `Проявка` |
| Имя хоста | адрес из /camera, вида `1-2-3-4.sslip.io` |
| Защищённый протокол | **Вкл** |
| Ошибка корн. сертификата | **Не подключаться** |
| Порт | `21` |
| Пассивный режим | **Вкл** |
| Каталог | `upload` |
| Пользователь / Пароль | `camera` и пароль из /camera |

## 4. Включи автоотправку

- **Функция передачи FTP → Вкл**, **Сервер 1** — выбран.
- **Автоперед. при съёмке → Вкл** — кадр улетает сразу после съёмки.
- **Тип файла для передачи: только JPEG** (бот обрабатывает JPEG и HEIF; RAW слать незачем — это долго и тяжело).
- Подключи камеру к Wi-Fi: **Меню → Сеть → Wi-Fi → Точка доступа** — точка доступа телефона или дом.

Сними кадр — через полминуты он в боте.

## Если не подключается

| Симптом | Что проверить |
|---|---|
| Ошибка сертификата | `cacert.pem` импортирован? Лежал в корне карты в слоте 1? |
| Ошибка входа | Пользователь `camera` (строчными), пароль из /camera без пробелов |
| Подключается, но файлы не приходят | Пассивный режим **Вкл**, каталог `upload` |
| Всё настроено, но нет сети | Камера подключена к Wi-Fi с интернетом? На телефоне включён «общий доступ»? |

Источник по пунктам меню — [справочное руководство Sony по FTP](https://helpguide.sony.net/di/ftp_2110/v1/en/contents/TP1000657906.html).
