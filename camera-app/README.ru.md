# Приложение «Проявка» для камер Sony

[English](README.md) · **Русский**

Кнопка «Отправить новые» для камер Sony с PlayMemories Camera Apps (Android 2.3 или 4.1 внутри): a5000/a5100, a6000/a6300/a6500, a7 II / a7R II / a7S II, RX100 III–V, RX10 II/III и другие из [списка совместимых](https://openmemories.readthedocs.io/devices.html). Пошаговая установка — [docs/sony-app.ru.md](../docs/sony-app.ru.md).

## Как пользоваться

1. Один раз: **Проявка → Wi-Fi** → выбрать сеть → ввести пароль. Приложение проверит подключение и запомнит сеть.
2. Снимайте в **JPEG** или **RAW+JPEG** (RAW не отправляется).
3. **Меню → Приложение → Проявка → Отправить новые.** Приложение включает Wi-Fi, подключается к одной из сохранённых сетей, отправляет кадры, показывает итог и выключает Wi-Fi. Кнопка корзины — отменить отправку, MENU — выход.

Отправленное записывается на карту (`PROYAVKA/sent.txt`) — повторно ничего не уходит, у каждой карты свой журнал. Чтобы отправить всё заново, удалите этот файл.

## Настройки на карте

`PROYAVKA/config.txt` делает мастер `setup.py`, бот присылает его по `/camera`:

```properties
url = https://1-2-3-4.sslip.io
token = токен-приёмника
lang = ru                  # ru / en; если нет — язык камеры
# prefix = a6300_          приставка к имени файла, по умолчанию — модель камеры

# необязательно: сети можно заранее вписать здесь, а не вводить на камере
wifi1.ssid = iPhone
wifi1.pass = пароль-точки-доступа
```

Сети, добавленные на камере, хранятся рядом в `PROYAVKA/wifi.txt` и главнее тех, что в `config.txt`. Обратный слэш в пароле пишется двойным: `\\`.

## Почему так

- **Сети хранит само приложение.** Камера держит список Wi-Fi на RAM-диске и восстанавливает его из резервной копии не при каждом выключении — отсюда «камера забыла Wi-Fi». Приложение при каждом запуске заново прописывает сохранённые сети.
- **Wi-Fi включается только на время отправки** и выключается на выходе — батарея не тратится, а фоновые процессы на этих камерах всё равно не живут.
- **HTTPS с собственными корневыми сертификатами.** В Android 4.1 нет корней Let's Encrypt и выключен TLS 1.2 (Android 2.3 знает только TLS 1.0 и шлёт на отдельный порт 8443 сервера, только для камеры); приложение несёт корни ISRG X1/X2/YE/YR и включает TLS 1.2 само, где может. Если у вашего сервера сертификат не от Let's Encrypt, добавьте его корень в `certs/` и пересоберите.
- **Проверка целостности.** Сервер возвращает SHA-1 принятого файла, приложение сверяет его со своим; не совпало — повтор, до трёх попыток.

## Сборка

Нужен Windows и PowerShell; всё остальное скрипт скачает сам (~300 МБ в `.tools`):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат — `Proyavka.apk`. Ключ подписи создаётся при первой сборке (`proyavka.keystore`). **Сохраните его:** обновить приложение поверх установленного можно только APK с тем же ключом. В git он не попадает.

`-Config my.properties` встраивает настройки прямо в APK (для личной сборки без файла на карте); `config.txt` на карте всё равно главнее.
